# KPI口径与业务边界

## 使用场景

该指标体系面向金融投诉运营分析人员，支持月度复盘、问题定位和异常下钻。数据来自CFPB公开数据库，不代表某家公司的内部客服工单，也不能单独评价公司服务质量。

## 核心指标

| 指标 | 公式 | 粒度 | 用途 | 主要限制 |
|---|---|---|---|---|
| 投诉量 | CFPB月度查询返回的投诉总数 | 自然月 | 观察公开投诉规模和变化 | 受市场规模、投诉倾向和CFPB收录范围影响 |
| 及时响应率 | `及时响应数 / 已知及时性投诉数` | 所选月份 | 观察公司响应及时性 | 必须使用分子分母加权，不能平均月度比例 |
| 救济率 | `(金钱救济 + 非金钱救济) / 投诉总数` | 所选月份 | 观察公开处理结果结构 | 不等于消费者满意或问题已彻底解决 |
| 处理中占比 | `In progress / 投诉总数` | 所选月份 | 识别近期数据成熟度 | 越新的月份通常更容易仍在处理中 |
| 转交时长 | `发送给公司时间 - CFPB接收时间` | 记录级质量样本 | 发现流程长尾 | 1,000条按月等额工程样本，不代表总体分布 |
| Narrative 主题数量 | `SUM(narrative_count)` | 月 × 产品 × NMF主题 | 描述公开原文中的文本聚类规模 | 主题非人工真值，不等于原因或伤害率 |
| Narrative 主题占比 | `主题叙事数 / 同范围全部叙事数` | 所选月份/产品 | 比较文本主题结构 | 仅覆盖主动公开叙事；不可代表全部投诉 |

## 诊断维度

- 产品：用于识别投诉集中在哪类金融产品。
- 问题：用于定位消费者报告的主要问题类型。
- 公司回复类型：用于拆解解释、金钱救济、非金钱救济、处理中和未及时回复。
- 提交渠道：用于观察Web、电话、转交和邮寄等渠道结构。
- 州：用于描述投诉来源地区，但没有人口分母时不得解释为地区风险率。

## 指标计算原则

1. 比率必须先汇总分子和分母再相除，不平均月度比例。
2. 趋势仅使用官方月度聚合结果；1,000条样本只用于记录级质量和流程长尾检查。
3. 最近月份的`In progress`比例具有成熟度偏差，不能直接与较早月份比较处理效率。
4. 公司投诉数必须结合客户规模或市场份额；当前项目不输出“最差公司排行榜”。
5. 数据库缺少消费者满意度和业务规模字段，因此不建立因果结论或服务质量综合评分。
6. Top-K 向量检索结果只用于案例证据；所有 Narrative 数量和占比必须从 `narrative_theme_monthly` 聚合。
