# 易错步骤与故障复盘

| 症状 | 根因 | 修复 | 如何验证 | 工程结论 |
|---|---|---|---|---|
| API 返回 404 | 给 CFPB 查询接口增加了不支持的 `format=json` 参数 | 删除该参数，按接口默认 JSON 解析 | 保存响应与来源回执 | 不能把浏览器 URL 习惯直接套到 API |
| API 返回 403 | 默认 HTTP 客户端 User-Agent 被服务端策略拦截 | 使用明确且可复现的兼容请求头 | 同一参数重试并记录状态 | 第三方 API 需要处理服务策略差异 |
| 翻页后出现重复 | `from`/排序组合未正确生效或结果页稳定性不足 | 固定排序，按 `complaint_id` 去重并检查唯一键 | 1,000 个 ID 全部唯一 | 分页成功不等于数据不重复 |
| 最新数据集中在很短时间 | 直接按最新记录截取造成时间偏差 | 改为按月定额工程抽样；总体趋势另用月度聚合 | 覆盖 20 个月，每月样本量检查 | 先匹配抽样方法与分析问题 |
| API 明细找不到文本 | 当前查询接口返回的 15 个字段不含 narrative | 转用 CFPB 官方 Narrative Archive，并与结构化 API 分开记录来源 | ZIP 字段、日期和回执对账 | 同一机构的不同发布渠道有不同数据合同 |
| ZIP 看似格式异常 | CFPB 对隐私字段使用 `123XX/XXXXX` 掩码 | 将官方掩码加入合法格式，不补全真实邮编 | 35 条掩码，非法格式 0 条 | 数据清洗要理解业务语义和隐私规则 |
| 月度率看起来不一致 | 简单平均每月百分比忽略分母差异 | 对整个区间汇总分子/分母后计算加权比例 | SQL 单元测试与总分母对账 | 指标治理比画图更重要 |
| SQL 白名单仍能读本地文件 | `read_csv_auto` 在 AST 中是匿名函数，`sql_name()` 返回 `ANONYMOUS` | 同时检查函数节点的真实 `name` | 恶意 SQL 测试必须被拒绝 | AST 方案也要做红队用例 |
| 包安装后 `ModuleNotFoundError` | macOS 给 `.venv` 下 `.pth` 文件加了 hidden flag，Python 3.12 跳过隐藏 `.pth` | 对虚拟环境执行 `chflags -R nohidden .venv` | `import project_agent` 与 pytest | 环境故障需定位到 Python 启动日志而非盲目重装 |
| 默认模型返回 404 | 当前组织未验证，不能使用配置的 `gpt-5-mini` | 对这一明确错误回退到账号可用的 `gpt-4.1-mini` | 真实端到端问数成功，记录实际模型 | 模型可见不等于有调用权限；回退必须可审计 |
| 第一次产品类别 SQL 聚合错误 | 模型把常量 `dimension` 当分组字段 | 工具结果让模型自检后第二次查询改为按 `value` 分组 | 轨迹保留两次 SQL | Agent 反馈闭环仍需评测和轨迹 |
| 混合分数报稀疏矩阵加法错误 | SciPy 矩阵乘法结果仍是稀疏列，`np.asarray` 没有转成普通数组 | 显式调用 `.toarray().reshape(-1)` | 临时三文档索引单元测试 | 科学计算对象的类型不能靠表面 shape 判断 |
| NMF 主题被 `XX/XXXX` 占位符主导 | CFPB 脱敏 token 高频，且产品分布不平衡 | 清理占位符/纯数字，唯一文本去重并按产品平衡抽样 | 对比前后主题词和全量分配 | 文本预处理必须结合数据发布规范 |
| 主题训练抽样抛出 `nsmallest` 类型错误 | 稳定抽样键是 SHA-256 字符串，pandas `nsmallest` 只支持可排序数值类型 | 改为 `sort_values('_stable').head(n)` | 固定种子重复运行 | 可复现抽样也要验证键类型与 API 合同 |
| RAG 在线测试返回零案例 | 模型自行设置 `min_score=0.70`，高于本地相关结果分数 | 工具 Schema 指定从 0.05 开始，零结果以不高于 0.20 重试 | 3 个在线 SQL/RAG/Hybrid 用例 | 相似度不是概率，阈值必须在本语料校准 |
| RAG 问题被误路由为 Hybrid | 路由规则用单字“率”和泛词“叙事/文本”，命中了“不要推断总体频率” | 改为具体指标词，并以“案例/原文/如何描述”识别 RAG 意图 | 新增边界语句路由测试 | 规则路由需要负向语境和边界用例 |
| Agent 先猜不存在的列 | 模型在查看 Schema 前假设 `topic_nm`、`narrative` 位于样本表 | 系统规则要求首次 SQL 前先取 Schema，主题查询使用受控聚合表 | 在线工具错误从 4 降为 0 | Schema 工具应成为执行前置条件，而非可选说明 |
